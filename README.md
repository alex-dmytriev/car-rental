# RentalCar Project

Car Rental is a web application to manage car rental process by customer.

### Get Started

- clone the repo locally
- num npm install
- you may use the project and improve it now

### Implemented features:

- Main page CTA banner
- Car catalog with pagination
- Search filter by brand, rental price and mileage
- Ability to add cars to the favorite list
- Detailed car information in a separate page
- Book form
